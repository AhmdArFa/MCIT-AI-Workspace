# Thoth AI Agent, Complete Brand Pack v1

Two logo candidates, both in OLED editions. Pick one as the final app icon, or keep both (one as the icon, one as a secondary mark).

- `cartouche/` — concept E: royal cartouche ring spelled T u T
- `layered-u/` — concept D: nemes stripes folded into the u of TuT

## File types in this pack and what each is for

- **SVG** (`svg/` folder): vector masters. Infinite scale, tiny file size. Use these in code, websites, Flutter/React Native assets, and any place a designer or developer needs the source artwork. Always edit the SVG first, then re-export PNGs.
- **PNG** (`icons/` folder): raster app icons at 14 sizes (1024 down to 16). Use the 1024 for the App Store / Play Store listing and as the source for platform-specific icon generators. The smaller sizes are ready-made for favicons, notifications, and in-app use.
- **Variants** (`variants/` folder): `mono-ivory` (single-color, for engraving, embossing, or strict one-color surfaces) and `light` (for light-mode surfaces), both at 1024.
- **Preview sheet** (PNG, one page): quick visual summary of the concept, sizes, palette, and construction. Send this to anyone who needs the gist without opening folders.
- **BRAND_PACK.md**: the written spec. Palette hex codes, construction geometry, clearspace, minimum size, and usage rules.

## Palette (shared across both concepts)

- #F7EF8A Pale Gold, primary accent
- #F8F5EC Ivory, letters and light marks
- #16A6E9 Pulse Blue (layered-u middle arch)
- #B7791F Bronze Gold and #1E507A Royal Blue / #1E1B4B Deep Navy (light variants only)
