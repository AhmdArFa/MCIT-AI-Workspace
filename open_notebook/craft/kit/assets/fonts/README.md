# Fonts

- Nohemi (headings): `Nohemi-Regular.ttf`, `Nohemi-Bold.ttf`; the variable
  `variable/Nohemi-VF.ttf` is kept for designers (renderers use the static weights).
  Provided by MCIT under its licence, from the document kit `templates/fonts/`.
- Libre Franklin (body): SIL Open Font License, `LibreFranklin-OFL.txt`.
- Inter (covers): SIL Open Font License, `Inter-OFL.txt`.

If the Nohemi files are ever removed, headings fall back to Libre Franklin and
the admin console lists the missing font.
