# Fonts

- Nohemi (headings): `Nohemi-Regular.ttf`, `Nohemi-Bold.ttf` (or `.otf`), plus the variable file.
  Provided by MCIT under its licence.
- Libre Franklin (body): SIL Open Font License, `LibreFranklin-OFL.txt`.
- Inter (covers): SIL Open Font License, `Inter-OFL.txt`.

Until the Nohemi files are installed, headings fall back to Libre Franklin and
the admin console lists the missing font.
