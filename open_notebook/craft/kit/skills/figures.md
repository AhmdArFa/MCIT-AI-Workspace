# Figures skill

- Every figure traces to real numbers from the notebook or the request.
- Palette: Pulse first, then Royal, Silver. One accent per figure.
- Quiet axes, no chart junk, value labels where they help, tabular numbers.
- Size for print (report column width) or slide width; check every render.
- Decks use native charts; reports use rendered figures.
