# Design helper (VectorCraft)

- Use for diagrams and one-off graphics placed inside documents.
- Chain commands in one run; style each object right after creating it;
  never restyle placed artwork.
- One accent, flat surfaces, hairline borders. No gradients, glows, glass or
  emoji icons.
- Export PNG and check alignment, overlaps and whitespace before use.
